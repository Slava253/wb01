# MarketPoint — первая рабочая версия

Это MVP маркетплейса + ПВЗ на чистых HTML/CSS/JS и Firebase.

## 1. Что уже работает

- клиентский вход по телефону + SMS Firebase;
- каталог товаров;
- корзина;
- выбор ПВЗ;
- создание заказа;
- QR-код заказа;
- история заказов;
- кабинет сотрудника ПВЗ;
- сканирование QR камерой;
- проверка, что заказ принадлежит этому ПВЗ;
- выдача заказа;
- оформление возврата;
- админ-панель;
- создание/редактирование ПВЗ;
- управление товарами;
- просмотр заказов и сотрудников.

## 2. Важное ограничение MVP

В чистом статическом сайте нельзя безопасно хранить Firebase Admin SDK secret и создавать пользователей Auth от имени администратора.

Поэтому на первом этапе сотрудника создайте вручную:
1. Firebase Console -> Authentication -> Users -> Add user.
2. Email: `логин@marketpoint.local`
3. Пароль: придумайте пароль.
4. Скопируйте UID созданного пользователя.
5. Firestore -> users -> Create document с ID = UID:
```json
{
  "role": "employee",
  "login": "pvz001",
  "name": "Иван",
  "pvzId": "ID_ПВЗ",
  "active": true
}
```

Для администратора аналогично:
```json
{
  "role": "admin",
  "login": "admin",
  "name": "Администратор",
  "active": true
}
```

После этого администратор сможет пользоваться панелью. Создание Auth-пользователей непосредственно из панели лучше сделать отдельной Firebase Cloud Function с Admin SDK — это следующий этап.

## 3. Firebase

Создайте Firebase-проект:
- Authentication: включите Phone и Email/Password.
- Firestore Database: создайте базу.
- Storage: создайте Storage.
- В Firebase Console добавьте Web App.
- Скопируйте конфигурацию в `js/firebase.js`.

Для Phone Auth также настройте разрешённые домены. При тестировании локально Firebase может потребовать reCAPTCHA.

## 4. Firestore

Коллекции:
- `users`
- `products`
- `pvz`
- `orders`

В проекте есть `firestore.rules`. Опубликуйте их в Firestore Rules.

Пример товара:
```json
{
  "name": "Наушники",
  "description": "Беспроводные наушники",
  "price": 2990,
  "stock": 10,
  "image": "https://...",
  "active": true
}
```

Пример ПВЗ:
```json
{
  "name": "ПВЗ №1",
  "address": "Москва, ул. Центральная, 1",
  "active": true
}
```

## 5. GitHub Pages

Загрузите все файлы репозитория и включите:
Settings -> Pages -> Deploy from branch -> main -> /root.

Открывать:
`https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`

Если GitHub Pages открывает `index.html`, он автоматически отправит пользователя на нужный кабинет.
