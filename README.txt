ПВЗ v2

Функции:
- QR и штрихкоды через камеру телефона;
- USB 2D-сканер как клавиатура + Enter;
- ручной ввод;
- разные звуки успешного и ошибочного сканирования;
- история последних 100 сканирований;
- панель администратора.

Администратор:
Логин: 2347
Пароль: 2203

Важно: это автономная демонстрационная веб-версия. История хранится в localStorage браузера. Для настоящей общей базы ПВЗ между разными телефонами/ПК нужен сервер или Firebase.
Камера телефона обычно требует HTTPS (например, GitHub Pages).
